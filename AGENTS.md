# Default V2 map pack merges

Whenever a contributor pack is merged or the default V2 pack is replaced,
follow and update the merge checklist and open issues in
[`docs/V2_DEFAULT_PACK.md`](docs/V2_DEFAULT_PACK.md). This includes auditing both
player-following rules and game-entrance bindings, not only images/checks.
Report newly assigned, missing and uncertain associations to Symon each time.
Regenerate [`docs/V2_PACK_CHECKLIST.md`](docs/V2_PACK_CHECKLIST.md) with
`npm run audit:v2Pack` and link to that complete report in the handoff.
